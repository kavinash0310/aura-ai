## Verification rule

Verification on 2026-11-07: GitHub Actions passed both push and pull-request workflows on commit `5493804` (backend, AI, web, and Compose). The current all-configured provider/filter changes pass local Maven verification (40 tests, 0 failures, 1 Docker-dependent skip), frontend tests (9 passed), and frontend production build; CI for these unpushed changes is pending. `uv` is not installed in this environment, and the Python service was not changed in this slice. Basic Auth is loopback development only. An authenticated explicit search sends a query to the selected provider or providers; uploaded files are not sent to search. The local model receives selected provider snippets only after an explicit report request; uploaded documents are excluded. FIRST receives exact CVE IDs only after authenticated lookup; AURA downloads CISA's catalog and matches locally. NVD receives exact CVE IDs only after an explicit per-item or batch request. Text/Markdown files are stored after explicit authenticated upload and searched locally. SBOM uploads are parsed in memory and only declared CVEs are submitted for KEV/EPSS enrichment; NVD detail is requested separately. Search results are partial and AURA does not fetch returned links. Reports validate source-ID membership but not semantic support. CVE and SBOM lookups are not asset discovery, vulnerability scanning, or a complete risk assessment.
