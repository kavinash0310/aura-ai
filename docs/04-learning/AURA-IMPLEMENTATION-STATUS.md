## Verification rule

Verification on 2026-11-11: PR #42 added credential-pattern masking before local inference; PR #43 added a synthetic offline redaction evaluator and narrowed a Basic-auth false positive found by that evaluator. Both PRs passed all four CI job groups. The AI suite ran 15 tests and the redaction evaluator reported 10/10 listed supported patterns detected, 3/3 benign fixtures unchanged, and 2/2 declared blind spots not detected; this controlled fixture score does not estimate real-world coverage. Basic Auth is loopback development only. Explicit public searches send a query to configured providers; uploaded files are not sent to search. Bluesky uses public post search only and does not connect to accounts. Local model report/claim actions receive selected public snippets; uploaded documents are excluded from those research routes. Document Q&A is a separate explicit action that sends only up to five selected bounded phrase-search excerpts to the local Ollama model. FIRST receives exact CVE IDs only after authenticated lookup; NVD and other advisory lookups are separately explicit. Search/provider coverage is partial, and CVE/SBOM features are not asset discovery or vulnerability scanning.
